# v1.3.0

[[NEW]] 在「我的 → 考试安排」查看学校公布的考试时间和地点。时间明确的考试也会显示在周课表和桌面小组件中。

[[NEW]] 开启课前提醒后，应用也会为有明确开考时间的考试安排本机提醒，提前时间沿用课前提醒设置。

[[NEW]] 考试查询与调课通知共用「设置 → 教务查询服务」中的服务地址。该页面提供凭据使用说明和配置自定义服务的风险提示。

[[OPTIMIZE]] 简化周课表顶部操作和样式设置，优化课程卡片、周切换和调课消息的查看体验。

[[OPTIMIZE]] 调整课程提醒设置，方便查看权限状态和提醒安排。改善课表同步和小组件的刷新及跳转体验，可在「设置 → 同步与修复」查看后台同步状态。
