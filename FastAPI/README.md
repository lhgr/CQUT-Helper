# 调课通知增强功能说明

“调课通知增强”是 CQUT Helper 的可选功能。它通过调课服务查询教务系统中的
待阅和已阅事项，识别当前学期的调课通知，并帮助应用及时刷新受影响的课表。

不开启该功能不会影响登录、普通课表同步、课前提醒或桌面小组件的基本使用。

## 可以做什么

开启后，应用可以：

- 查询当前学期的调课通知。
- 识别新增、内容变更和撤销的调课记录。
- 根据通知中的周次，只重新同步可能受影响的教学周。
- 在课表页面展示与当前课程相关的调课提示。
- 在消息中心保存本机调课记录，便于之后查看。
- 在通知权限允许时发送调课提醒。

首次成功查询主要用于建立本机基线，通常不会把所有历史通知重新提醒一遍。之后
发现通知新增、改变或消失时，应用才会生成对应记录并更新相关课表。

## 如何开启

可以从以下任一入口进入设置：

- “设置 → 通知与提醒 → 调课通知”
- “课表 → 右上角设置 → 调课通知增强”

操作步骤：

1. 先登录并打开一次课表，确保应用已经获取当前学期信息。
2. 开启“调课通知增强”。
3. 阅读隐私说明，确认同意后继续。
4. 调课服务地址留空时使用官方服务；需要自建服务时，在高级设置中填写 HTTPS
   域名。
5. 保存设置后点击“检查服务可用性”。该检查会使用当前登录凭据实际查询一次
   当前学期，而不只是检查服务器能否打开。
6. 如需后台提醒，请允许通知权限，并根据手机系统检查自启动和电池优化设置。

自定义服务地址只接受不带接口路径、查询参数或片段的 HTTPS 地址，例如：

```text
https://notice.example.com
```

配置自定义服务后，应用只会把凭据发送到该服务。自定义服务不可用时会直接提示
失败，不会静默回退到官方服务。

## 后台检查时间

启用后，应用通常按北京时间执行：

- **9:00**：当天主要检查任务。
- **12:00**：上午任务失败时的补跑。
- **0:00—7:00**：暂停后台查询，白天再继续。

Android 可能因为省电模式、后台限制、设备重启或长期未打开应用而延迟任务。
“设置 → 同步与诊断”会显示最近一次运行和成功时间，并区分以下状态：

- 观察中：刚开启，系统还在建立后台任务记录。
- 运行正常：近期已经成功检查。
- 夜间暂停：当前处于主动跳过的深夜时段。
- 上午失败：会等待 12:00 补跑。
- 今日已失败：9:00 和 12:00 均未成功，次日会重新尝试。
- 可能受系统限制：长时间没有检测到应有的后台执行记录。

后台状态异常时，可先打开应用检查登录和网络，再重新保存设置；仍无改善时，请
允许应用自启动、后台运行并忽略电池优化。

## 查询结果如何使用

调课服务返回的是当前学期的完整调课结果。应用会与上一次结果比较：

- 新通知：记录调课内容并刷新受影响周。
- 已有通知发生变化：更新记录并重新同步相关周。
- 原有通知被撤销或不再存在：记录“撤销调课通知”，并重新同步原先受影响的周。
- 完整结果为空：表示当前学期没有可用调课通知，不等同于服务故障。

如果通知原文格式不完整，应用可能无法准确识别课程、周次或节次。此时消息中心
仍会保留可用的原始信息，并提示查看调课记录；重要安排请以学校官方通知为准。

## 数据与隐私

只有开启“调课通知增强”并确认隐私提示后，应用才会向所选服务发送：

- 学号
- 教务系统使用的加密密码
- 当前学年学期

加密密码不是明文密码，但能够用于访问教务系统，因此仍属于敏感凭据。官方服务
程序不会主动保存请求内容，但服务器运营商、反向代理或日志平台仍需要正确关闭
请求体记录。

关闭功能后，应用不会继续访问官方或自定义调课服务。退出登录时，应用也会关闭
调课通知增强并清除已接受的授权状态，下次开启时需要重新确认。

消息中心的调课历史保存在本机。清空消息中心只会删除本机记录，不会修改学校
课表或教务系统中的通知。

## 官方服务与自建服务

### 官方服务

服务地址留空时使用应用内置的官方服务。适合希望直接使用功能、不自行维护服务器
的用户。

### 自建服务

自建服务适合希望自行控制凭据处理环境的用户。自建地址必须：

- 使用有效的 HTTPS。
- 与 CQUT Helper 当前调课服务协议兼容。
- 能正常访问学校统一认证和教务系统。
- 妥善限制访问、保护日志并及时安装安全更新。

在应用中点击“检查服务可用性”成功后再长期启用。自建服务的隐私保护、稳定性和
数据安全由服务运营者负责。

## 常见提示

| 提示 | 常见原因 | 建议操作 |
| --- | --- | --- |
| `登录凭据缺失` | 已退出登录，或本机凭据不可用 | 重新登录后再检查 |
| `当前学期信息缺失` | 尚未成功打开或同步课表 | 先进入课表完成同步 |
| `接口夜间关闭(403)` | 学校上游接口当前不可用 | 白天时段重试 |
| `请求过于频繁` | 短时间内多次手动检查 | 稍后再试，避免连续点击 |
| `服务繁忙` | 服务当前正在处理其他查询 | 稍后重试 |
| `查询超时` | 学校系统、网络或浏览器流程响应过慢 | 检查网络后稍后重试 |
| `数据完整性未确认` | 服务返回了不完整或旧版格式 | 更新服务，或改用兼容地址 |
| `服务不可用` | 地址错误、证书异常或服务器离线 | 确认只填写 HTTPS 域名并重新检查 |

健康检查成功只代表服务进程在线，不代表学校统一认证和教务系统一定可用。应用内
的“检查服务可用性”会完成一次真实查询，因此更适合判断当前是否可以使用。

## 使用提醒

- 调课通知增强用于辅助发现变化，不能替代学校官方通知。
- 后台任务和通知到达时间可能受手机系统限制，无法保证精确到分钟。
- 不要使用来源不明的自建调课服务，也不要向他人提供自己的登录凭据。
- 发现课表与官方信息不一致时，请先在应用内主动同步，再以学校官方信息为准。
